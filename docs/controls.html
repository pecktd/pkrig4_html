pkrig4.controls

controls

Animation controls: curve, color, zero/offset groups and controller tag in one call.

Example:

from pkrig4 import controls, shapes
from pkrig4.naming import Side

arm = controls.create_control("arm", "fk", side=Side.LEFT, shape=shapes.CUBE, match=jnt)
arm.ctrl.rotate >> jnt.rotate
# L_arm_fk_ctrl_zr > L_arm_fk_ctrl_ofst > L_arm_fk_ctrl

ik = controls.create_control("arm", "ik", side=Side.LEFT, joint=True, match=wrist)
# a joint control aligned to the wrist through jointOrient; rotate reads 0 at rest

def create_control(
    *parts: str,
    side: Side = Side.CENTER,
    shape: shapes.CurveShape = shapes.CIRCLE,
    size: float = 1.0,
    color: Color | None = None,
    parent: DagNode | str | None = None,
    match: Transform | str | None = None,
    locked: Sequence[str] = ('visibility',),
    joint: bool = False,
) -> Control | JointControl

Create a control under offset and zero groups.

Args
*parts
Name parts, e.g. "arm", "fk" → L_arm_fk_ctrl.
side
Side token for the name, and the default color.
shape
Curve shape from pkrig4.shapes.
size
Uniform scale applied to the shape's CVs.
color
Index color; defaults to side_color.
parent
Parent for the zero group.
match
Transform to snap to. A transform control's zero group takes its position and orientation. A joint control's zero group takes only the position, and the control's orientation goes into its jointOrient, so its rotate channels read zero at rest.
locked
Attributes to lock and hide on the control.
joint
Build the control as a joint (bone display hidden, radius locked) instead of a transform; returns a JointControl. Use it for IK controls that must align to a joint while keeping clean rotate values.
