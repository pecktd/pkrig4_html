pkrig4.data_io.files

data_io.files

Paths, JSON files and the read log shared by the data_io modules.

Relative paths resolve against the open scene's folder, so a workspace's build.py can say "control.crv" and mean the file next to build.ma.

Example:

from pkrig4.data_io import files

files.start_log()                     # build.dep lists every data file read
files.write_json("notes.json", {"cvs": [[0, 0, 0], [1, 0, 0]]})
files.read_json("notes.json")

def write_json(path: PathLike, data: Any) -> Path

Write data as JSON that diffs well and return the absolute path.

Lists of numbers and strings stay on one line, so a curve's CVs or a skin's weights don't take one line per value. Parent folders are created. The file is written to a temporary name first, so a failed write never leaves half a file behind.

def start_log(path: PathLike = 'build.dep') -> Path

Start a fresh read log; every data file read afterwards is listed in it.

A build calls this first, so the log shows which files the rig was built from.

def stop_log() -> None

Stop recording reads.

def record(path: PathLike) -> None
