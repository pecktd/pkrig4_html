pkrig4.ui.export

ui.export

Exporting from the Maya selection: what it can write, where to, and what that changes; no Qt.

The workspace window's Export panel shows one ExportOption per kind of data the selection has: skin weights, ngSkinTools layers and blend shapes of the selected meshes (or every mesh under a selected group), values of the selected nodes, the selected joints' skeleton. Control shapes don't need a selection: they're always every control in the scene.

Example:

from pkrig4.ui import export

for option in export.options_for_selection():
    target = export.default_target(option, workspace_folder)
    text, replaced = export.preview(option, target)   # "replaces Body_Geo.skin · adds Hair_Geo.skin"
    export.run(option, target)

Where to export by default.

In order: the file selected in the window if it's this type; the last target used for this type; the file the build reads for this type; the type's default name in the workspace.

def preview(option: ExportOption, target: Path) -> tuple[str, list[str]]

What exporting to target changes, and the existing files it replaces.

Control shapes update the controls they write and keep the rest, so they replace nothing the window needs to ask about.

def run(option: ExportOption, target: Path) -> str
