pkrig4.ui

ui

pkrig4's Maya UI: the workspace window.

Only this package imports Qt (through pkrig4.ui.qt), so builds in mayapy and batch never load it. pkrig4.ui.model and pkrig4.ui.actions hold the logic and have no Qt.

Example:

from pkrig4 import ui

ui.show()                                         # the open scene's workspace
ui.show("D:/proj/rnd/assets/harold/work/rig/default")
