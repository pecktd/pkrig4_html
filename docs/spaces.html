pkrig4.spaces

spaces

Space switching: let a control follow one of several parents.

Example:

from pkrig4 import spaces

spaces.add_space_switch( head.ctrl_zr, [(head.ctrl, "head"), (cog.ctrl, "cog"), (main.ctrl_grp, "world")], controller=head.ctrl, ) # head.ctrl gets an enum "parentTo": local / head / cog / world

Constrain driven to a choice of spaces picked by an enum on controller.

Args
driven
Transform that follows the chosen space, usually a control's zero group.
spaces
(space, label) pairs.
controller
Node that gets the enum attribute.
kind
"parent", "orient" or "point"; also names the attribute (parentTo, orientTo, pointTo).
include_local
Prepend driven's current parent as a local space.
default
Index of the space selected at build time.
