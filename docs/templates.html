pkrig4.templates

templates

Build templates: Builder subclasses that workspaces inherit.

A workspace's build.py subclasses a template and changes only what differs, so a fix to the template reaches every workspace on its next build.

PropBuildOne control and joint at cog_guide; the model bound rigidly
BipedBuildSpine, clavicles, arms, hands, legs, neck and head

Example:

from pkrig4 import builder
from pkrig4.templates import PropBuild

class Build(PropBuild):
    model_file = "D:/assets/robotArm/model/high.abc"

    @builder.step(after="rig")
    def antenna(self):
        ...
