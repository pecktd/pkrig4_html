pkrig4.component

component

Rig components: a naming context, a tagged root group, and named member roles.

A component (an arm, a leg, an FK chain) subclasses Component. Its root group records which class built it, its side and name, and the pkrig4 version, once. Every node the component makes is linked to the root with a *role*, so tools and error reports can get from any node back to its component, and from a component to its parts, without parsing names.

Example:

class FkChain(pk.Component):
    def __init__(self, guides, *, side=pk.Side.CENTER, parent=None):
        super().__init__("tail", side=side, parent=parent)
        ctrl_parent = self.root
        for index, guide in enumerate(guides):
            jnt = self.joint(str(index + 1), target=guide, role="jnt", index=index)
            fk = self.control(str(index + 1), "fk", match=jnt, parent=ctrl_parent,
                              role="fk_ctrl", index=index)
            constraints.parent_constraint(fk.ctrl, jnt)
            ctrl_parent = fk.ctrl

info = pk.component_of("tail_2_fk_ctrl")     # from any node back to its component
info.cls, info.side, info.version, info.role_of("tail_2_fk_ctrl")
info.members("fk_ctrl")                      # all FK controls, in order

If a component's __init__ raises, the error is re-raised as ComponentBuildError naming the component, its class and the pkrig4 version; the original error is kept as its cause.

def name_for(*parts: str, suffix: str) -> str

Compose a name inside this component: name_for("upper", suffix="jnt") → L_arm_upper_jnt.

def add_member(member: N, role: str = '', *, index: int | None = None) -> N

Link a node to this component, optionally with a role, and return it.

Roles name what a node is for ("fk_ctrl", "ik_ctrl", "pole_vector"). index orders repeated roles: role="fk_ctrl", index=0 is stored as "fk_ctrl.0". Nodes added without a role are still traceable to the component.

def create(
    factory: Callable[..., N],
    *parts: str,
    suffix: str,
    role: str = '',
    index: int | None = None,
    **kwargs: Any,
) -> N

Create a node named for this component and link it as a member.

factory is a pkrig4.node type; kwargs go to it:

blend = self.create(node.pairBlend, "upper", suffix="pbl")
grp = self.create(node.transform, "ik", suffix="grp", parent=self.root)
def control(
    *parts: str,
    role: str | None = None,
    index: int | None = None,
    joint: bool = False,
    **kwargs: Any,
) -> controls.Control | controls.JointControl

controls.create_control named and colored for this component.

The zero group is parented under the root unless parent= is given. The control is registered with role (default: its name parts joined by _); its offset and zero groups are registered without a role. Other keyword arguments go to controls.create_control.
