pkrig4.naming

naming

Naming convention.

Names follow [side]{sep}part{sep}part...{sep}suffix, e.g. L_arm_ik_ctrl. The tokens come from the active Convention, so swapping conventions changes every name composed or parsed afterwards, including Side.token.

This module does not import Maya.

def compose(*parts: str, side: Side = Side.CENTER, suffix: str) -> str

Join tokens into a name.

Example

def parse(name: str) -> NameParts

Split a name into side, parts and suffix.

DAG paths and namespaces are ignored: |grp|ns:L_arm_ctrl parses as L_arm_ctrl.

Example
>>> parse("L_arm_ik_ctrl")
NameParts(side=<Side.LEFT: 'left'>, parts=('arm', 'ik'), suffix='ctrl')
