pkrig4.ui.actions

ui.actions

What the workspace window can do with a file, a pack or the open scene; no Qt here.

Each Action says what it changes, so the window knows when to ask first: only when the open scene belongs to another workspace, when a file would be overwritten, or when unsaved changes would be lost.

Example:

from pkrig4.ui import actions, model

info = model.find_workspaces("D:/proj/rnd/assets/harold/work/rig/default")[0]
for group in model.scan_files(info.path):
    for entry in group.entries:
        for action in actions.actions_for(entry, info):
            action.label, action.enabled
