pkrig4.data_io

data_io

Write rig data to files and read it back in a build.

Every kind of data is a DataType subclass with the same two methods: write(path=None, nodes=None) saves from the scene, read(path=None, nodes=None) applies to the scene. Paths may leave out the extension, and relative paths start at the open scene's folder, so a workspace's build.py names files next to it.

data_types lists every registered type (for tools and UIs); files holds the shared path, JSON and read-log helpers.

Example:

from pkrig4 import data_io

data_io.files.start_log()             # build.dep lists every file read
# ... build the rig ...
data_io.Curves().read()
data_io.Skin().read()

for name, data_type in data_io.data_types().items():
    data_type().write()               # export everything

One kind of rig data, saved to and loaded from one file or folder.

Subclasses set the class attributes and implement write and read. Options go to __init__, so write and read keep the same signature in every subclass.

def read(
    path: files.PathLike | None = None,
    nodes: Iterable[Node | str] | None = None,

Apply the saved shapes to the controls they name; return the controls changed.

A control not found by its full path is looked up by its short name, so the file survives regrouping. Controls missing from the scene are skipped. Shapes are added or deleted so each control ends with as many as the file.
