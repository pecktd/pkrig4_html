pkrig4.builder

builder

Rig builds: a workspace's build.py as a Builder with named steps.

BuilderBase class; methods marked @step run in order, then load_data, finalize and save
stepMarks a step; @step(after="rig") places it
WorkspaceA workspace folder, its asset and variant, its paths
runLoad a workspace's build.py and build it (until=)
save_dataWrite the build's data files from the open scene
BuildReportStep times, data files read and warnings
BuildErrorA step failed; .report says how far it got

A workspace's build.py:

from pkrig4 import builder, data_io
from pkrig4.templates import PropBuild

class Build(PropBuild):
    model_file = "D:/assets/robot/model/high.abc"

    @builder.step(after="rig")
    def antenna(self):
        ...

Headless: mayapy -m pkrig4.builder <workspace> [--until STEP].

class Builder(workspace: Workspace | files.PathLike)

Base class for rig builds.

Args
workspace
The workspace to build in; build.ma and build.dep are written there and the build's data files are read from there.
def run(until: str | None = None) -> BuildReport

Build from a new scene, through step until (default: all steps).

The scene is named build.ma in the workspace first, so relative data_io paths start there. build.dep lists the data files read.

Raises
ValueError
until isn't a step.
BuildError
A step raised. The scene is left as the step left it.
