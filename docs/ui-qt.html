pkrig4.ui.qt

ui.qt

The one place pkrig4 imports Qt: PySide6 (Maya 2025+) or PySide2 (Maya 2024).

Import Qt from here, never from PySide directly, and write enums in full (QtCore.Qt.AlignmentFlag.AlignLeft, not QtCore.Qt.AlignLeft): the full form works in both bindings. The names below smooth over what moved in Qt 6.

Example:

from pkrig4.ui.qt import QAction, QtCore, QtWidgets, exec_dialog

action = QAction("Build", parent)
if exec_dialog(dialog) == QtWidgets.QDialog.DialogCode.Accepted:
    ...
