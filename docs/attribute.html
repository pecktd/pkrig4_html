pkrig4.attribute

attribute

Attribute (plug) wrapper.

An Attr is a node plus an attribute path ("translateX", "worldMatrix[0]", "value[2].value_Position"). Because it keeps a reference to its Node rather than a name string, it stays valid when the node is renamed or reparented.

All edits go through maya.cmds so they are undoable.

class Attr(node: Node, path: str)

A plug on a node, e.g. ctrl.translateX.

Example
>>> ctrl.translate.value = (0, 1, 0)
>>> ctrl.translateX >> other.translateY
>>> ctrl.worldMatrix[0] >> decompose.inputMatrix
>>> ctrl.translateX.connect(other.translateY, force=False)
