pkrig4.ui.model

ui.model

What the workspace window shows, worked out from the files on disk; no Qt here.

Example:

from pkrig4.ui import model

folder = "D:/proj/fuji4/assets/eggPawn/work/rig/default"
for info in model.find_workspaces(folder):
    info.name, info.kind, info.stage        # "layout5", "pkrig3", "Layout"
for group in model.scan_files(f"{folder}/layout5"):
    group.label, [entry.name for entry in group.entries]
model.next_version(f"{folder}/layout5", "skin")   # "skin_2.ma"

def scan_files(workspace: str | Path) -> list[Group]

A workspace's files grouped by kind; empty groups are left out.

Maya, FBX and Alembic files, build.ma and numbered work scenes included, are one "Scenes" group sorted by name (skin_2 before skin_10). Names starting with . or _ and plain folders are skipped, as are __pycache__ and build.dep.
