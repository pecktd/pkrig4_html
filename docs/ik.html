def ik_handle(
    start: Transform | str,
    end: Transform | str,
    name: str,
    *,
    solver: str = 'ikRPsolver',
    curve: DagNode | str | None = None,
    parent: DagNode | str | None = None,
) -> node.ikHandle

An IK handle from start to end; its effector is named <name>_eff.

Args
start
First joint of the chain.
end
Joint the handle moves.
name
Handle name.
solver
"ikRPsolver" (pole vector), "ikSCsolver" (no twist plane) or "ikSplineSolver" (with curve).
curve
Existing curve for a spline handle; the joints should lie on it.
parent
Parent for the handle.
def pole_vector_position(
    start: Transform | str,
    mid: Transform | str,
    end: Transform | str,
    *,
    distance: float = 1.0,
) -> om.MVector

A pole vector position on the bend side of mid.

The point lies on the line from the start-to-end line through mid, distance times the chain's length away from the start-to-end line.

Raises
ValueError
The three points are in a line, so there is no bend side.
