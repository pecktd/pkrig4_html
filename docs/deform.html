deform

Deformer helpers: skinning, blend shapes, wraps and clean duplicates.

from pkrig4 import deform

skin = deform.bind_skin(jnts, "body_GEO")
deform.connect_bind_pre_matrix(skin, exclude=["tweaker_master_jnt"])
deform.add_front_blend_shape("facialRig:body_GEO", "body_GEO")
wrap = deform.proximity_wrap("eyelash_GEO", ["head_GEO"])

None of these use the selection.

def connect_bind_pre_matrix(skin: Node | str, *, exclude: Iterable[str] = ()) -> None

Drive each influence's bindPreMatrix from its parent's worldInverseMatrix.

The skin then deforms only with motion relative to each joint's parent, so a whole skinned setup can ride along with its parent (e.g. facial skin on a moving head). Influence indices are read from the actual connections, so removed or reordered influences are handled.
