from pkrig4 import joints, node

jnt = joints.create_joint_at("L_upper_arm_guide", "L_upper_arm_jnt")
joints.orient_chain(jnt)                       # aim +Y down the chain, up +X
zero = joints.create_zero_group(ctrl)          # "L_arm_ctrl_zr", in place

Every function edits the scene through maya.cmds, so each one is undoable.

def create_joint_at(
    target: Transform | str,
    name: str | None = None,
    *,
    parent: DagNode | str | None = None,
) -> node.joint

Create a joint at target's world position and orientation.

The orientation is stored in jointOrient and rotate is left at zero, so the joint can be posed from a clean rest.

def create_zero_group(
    dag: Transform | str,
    name: str | None = None,
    *,
    suffix: str = 'zr',
) -> node.transform

Insert a group directly above dag that holds its current transform.

The group takes dag's place under its original parent and matches its world transform, so dag's local translate, rotate and scale become identity. Call it again on the result to stack groups (ofst under zr, and so on).

Args
dag
Transform to zero.
name
Group name. Defaults to dag's name plus suffix, joined with the active convention's separator (L_arm_ctrl_zr).
suffix
Used only when name is not given.

def orient_joint(
    jnt: Transform | str,
    *,
    aim_axis: Vector = (0, 1, 0),
    up_axis: Vector = (1, 0, 0),
    up_vector: Vector | None = None,
) -> None

Aim a joint at its first child joint, keeping every child where it is.

The new orientation is stored in jointOrient. A joint with no child joints takes its parent's orientation (rotate and jointOrient zeroed), which is the usual choice for chain ends.

Args
jnt
Joint to orient.
aim_axis
Local axis that points down the chain.
up_axis
Local axis that leans toward up_vector.
up_vector
World direction for up_axis. Defaults to that axis's current world direction, so the joint keeps its twist.
