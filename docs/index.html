pkrig4

A Maya rigging framework: typed node and attribute wrappers with editor autocomplete, the rigging helpers build scripts reach for most often, rig data I/O, step-based workspace builds, body components, and a workspace window for working in Maya.

0.1.0 is the first beta. The API can still change between minor versions before 1.0; each change is listed in the release notes.

import pkrig4 as pk
from pkrig4 import constraints, controls, joints, node, scene, shapes, spaces

side = pk.Side.LEFT
rig = node.transform("rig_grp")

jnt = joints.create_joint_at("L_wrist_guide", "L_wrist_jnt")
fk = controls.create_control("wrist", "fk", side=side, shape=shapes.CUBE, parent=rig, match=jnt)
constraints.parent_constraint(fk.ctrl, jnt)

ik = controls.create_control("arm", "ik", side=side, joint=True, parent=rig, match=jnt)
spaces.add_space_switch(ik.zero, [("cog_ctrl", "cog"), ("world_ctrl", "world")], controller=ik.ctrl)

md = node.multiplyDivide()            # node. and md. both autocomplete
fk.ctrl.tx >> md.i1x
md.op.value = pk.MultiplyDivideOp.DIVIDE

scene.delete_if_exists("guide_grp")
scene.set_joint_radius(0.2)

A workspace's build.py is a Builder with steps; the workspace window builds it, step by step if you like, and exports the selection's data into the workspace:

from pkrig4 import builder, data_io
from pkrig4.templates import BipedBuild

class Build(BipedBuild):
    data = (data_io.Curves(), data_io.Skin())

    @builder.step(after="head")
    def tail(self):
        ...

# In Maya:
from pkrig4 import ui
ui.show()

Install

pkrig4 needs Maya 2024 or later (Python 3.10+). Put the folder that contains pkrig4 on Maya's Python path, for example in userSetup.py or Maya.env:

import sys
sys.path.insert(0, "C:/dev")   # the parent of the pkrig4 folder

import pkrig4 as pk
print(pk.__version__)

Add the parent folder, not C:/dev/pkrig4 itself. pkrig4 is imported as a package, and putting its own folder on the path would let its modules shadow others with the same name.
