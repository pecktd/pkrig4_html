pkrig4.core

core

Node wrappers.

Every Maya node is wrapped by one of four classes, picked by wrap:

Node            any dependency node
└── DagNode     anything in the DAG (shapes included)
    └── Transform
        └── Joint

For typed, autocompleting access per Maya node type (node.multiplyDivide()), see pkrig4.node, which builds on these.

A wrapper holds an MObjectHandle, so it survives renames and reparenting. Attributes are reached generically: node.translateX returns an Attr for any attribute the node has, built-in or dynamic. Python members win over Maya attributes of the same name; use node.attr("name") in that case.

Queries use OpenMaya 2.0; every edit goes through maya.cmds so it is undoable.

Create a node from a type name, without touching the selection.

Prefer node.<type>() from pkrig4.node when the type is known while writing the code; it is typed for the editor. Use this when the type is only known at runtime (data-driven builds). Shape types created without a parent get a new transform; the shape is returned.
