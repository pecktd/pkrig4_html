pkrig4.connect

connect

Connection patterns between transforms and attributes.

Example:

from pkrig4 import connect

connect.connect_transforms(ctrl, jnt)                     # t, r, s
connect.blend_transforms(fk_jnt, ik_jnt, jnt, ctrl.fkIk)  # 0 = fk, 1 = ik
connect.multiply(close.output, 0.03, neck.ctrl_ori.ty)

def blend_transforms(
    first: Transform | str,
    second: Transform | str,
    target: Transform | str,
    weight: Attr,
    *,
    name: str | None = None,
) -> node.pairBlend

Drive target's translate and rotate from a blend of two transforms.

weight 0 follows first, 1 follows second. Rotation blends as a quaternion (shortest path), so it doesn't flip like an Euler blend.
