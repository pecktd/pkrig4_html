pkrig4.shapes

shapes

Controller curve shapes.

Each shape is a CurveShape constant (CIRCLE, CUBE, ...); look one up by name with SHAPES["cube"]. Attach a shape to a transform with add_curve, or make a new curve transform with create_curve.
